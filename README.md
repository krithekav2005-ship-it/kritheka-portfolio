# Kritheka V — Professional Portfolio

A responsive portfolio website built with plain HTML, CSS and JavaScript. No build step or framework is required.

## Run locally
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in your browser, or use VS Code with Live Server.

## Before publishing — important checks
- Verify your current degree status, institution name, dates and final CGPA.
- Verify internship title, employer, dates and responsibilities. Replace the timeline's verification notes with accurate details.
- Verify every project description and technology list against the actual code you wrote.
- The Inventory Management System link points to the GitHub repository URL previously supplied. Confirm it opens and is public if you want recruiters to see it.
- The Breast Cancer Prediction and Expense Tracker buttons currently link to your GitHub profile, not verified project repositories. Replace them with the exact repository URLs; add a live demo only if one exists.
- Add your current resume as `resume.pdf` and add a download button if desired. A resume link is intentionally omitted until the file is provided.
- Confirm that the displayed email and LinkedIn profile are current. This version omits your phone number to reduce unnecessary exposure; add it back only if you want it public.
- Only list skills you can comfortably explain in an interview. Add Spring Boot after you have hands-on experience.

## Contact form behavior
The form prepares an email using `mailto:`. It does not send messages directly and requires the visitor to have an email app configured. No form data is stored by this static website.

## Publish with GitHub Pages
1. Create or choose a GitHub repository for the portfolio.
2. Upload the three site files to the repository's root.
3. In the repository, open **Settings → Pages** and configure deployment from the `main` branch and `/ (root)`.
4. Wait for GitHub Pages to publish the site, then open the generated URL and test all links on desktop and mobile.
